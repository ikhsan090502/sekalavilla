Kebutuhan Endpoint REST API

Saat ini sistem berjalan menggunakan LocalStorage (Mock Persistence) yang aman & instan. Untuk menghubungkan ke Database / Backend REST API Anda, siapkan endpoint di bawah ini:

POST Autentikasi

/api/auth/login

Menerima payload { username, password } dan merespons dengan JWT Bearer Token.

GET / POST / PUT / DELETE Banner Slider

/api/banners

Menyimpan gambar URL banner (rasio wide), status ada/tidaknya teks (has_text: boolean), headline, subtext, dan urutan slide.

GET / POST / PUT / DELETE Katalog Villa

/api/villas

CRUD data unit villa: nama, tier kategori (Budget/Standard/Premium), array gambar (rasio 1:1), kapasitas tamu, dan filter fasilitas.

GET / PUT Format Pesan WA

/api/settings

Pengaturan nomor WhatsApp CS admin dan format template pesan interaktif dengan tag variabel.

File Spesifikasi Lengkap: API_SPECIFICATION.md

Kami telah men-generate dokumentasi spesifikasi payload request/response JSON lengkap di repository: API_SPECIFICATION.md. Backend developer (Node.js, Laravel, Go, atau Python) dapat langsung mengikutinya.
